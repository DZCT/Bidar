# 🤖 Telegram Userbot — همیشه آنلاین + پاسخ خودکار

یه یوزربات ساده و پایدار با **Telethon** که اکانت تلگرامت رو دائمی آنلاین نگه میداره و بهت قابلیت‌های پاسخ خودکار و دستورات سفارشی میده.

---

## ✨ قابلیت‌ها

- 🟢 **آنلاین دائم** با ری‌کانکت خودکار
- 💤 **حالت AFK** با متن دلخواه
- ⏳ **Cooldown هوشمند** (به هر کاربر فقط یه بار در بازه زمانی پاسخ میده)
- 🤖 **نادیده گرفتن ربات‌ها** و گروه‌ها (فقط چت خصوصی)
- 📊 آمار زنده: آپ‌تایم، تعداد پیام‌ها و پاسخ‌های خودکار
- 📝 لاگ فایل برای بررسی
- 🛠 دستورات داخلی: `.ping`, `.afk`, `.alive`, `.stats`, `.help`, `.id`

---

## 📋 پیش‌نیازها

- Python 3.10+
- یه VPS لینوکسی (Ubuntu/Debian پیشنهاد میشه)
- **API_ID** و **API_HASH** از [my.telegram.org](https://my.telegram.org/apps)
- شماره موبایلی که با اکانت تلگرامت فعاله

---

## 🚀 نصب و اجرا روی VPS

### ۱. انتقال فایل‌ها به سرور
```bash
scp -r telegram_userbot root@YOUR_VPS_IP:/opt/
ssh root@YOUR_VPS_IP
cd /opt/telegram_userbot
```

### ۲. نصب پایتون و ساخت محیط مجازی
```bash
apt update && apt install -y python3 python3-venv python3-pip
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

### ۳. تنظیم متغیرهای محیطی
```bash
cp .env.example .env
nano .env
```
مقادیر `API_ID`, `API_HASH`, `PHONE` رو با اطلاعات خودت پر کن.

### ۴. اجرای اولیه (برای لاگین و گرفتن کد)
```bash
python userbot.py
```
- تلگرام یه کد تایید به اکانتت میفرسته → توی ترمینال وارد کن
- اگه ۲FA داری، پسوردت رو هم بزن
- اگه موفق شد، یه فایل `userbot_session.session` ساخته میشه
- با `Ctrl+C` ببندش

> ⚠️ **نکته امنیتی:** فایل `.session` خیلی حساسه! اگه لو بره کسی میتونه به اکانتت دسترسی بگیره.

### ۵. راه‌اندازی به صورت سرویس دائمی با systemd

```bash
cp userbot.service /etc/systemd/system/
systemctl daemon-reload
systemctl enable userbot
systemctl start userbot
```

### ۶. بررسی وضعیت
```bash
systemctl status userbot        # وضعیت سرویس
journalctl -u userbot -f        # لاگ زنده
tail -f /opt/telegram_userbot/userbot.log
```

## 💬 دستورات یوزربات

دستورات رو فقط **خودت** (توی هر چتی) می‌تونی تایپ کنی:

| دستور | توضیح |
|---|---|
| `.ping` | تست زنده بودن و تاخیر |
| `.afk [متن دلخواه]` | روشن کردن AFK با متن سفارشی |
| `.afk` (بار دوم) | خاموش کردن AFK |
| `.alive` | وضعیت ربات و آپ‌تایم |
| `.stats` | آمار کامل (پیام‌ها، پاسخ‌ها، آپ‌تایم) |
| `.id` | نمایش آیدی چت فعلی |
| `.help` | لیست تمام دستورات |

### مثال استفاده
```
.afk بعد از ظهر برمیگردم 🌙
```
هر کی بهت پیام خصوصی بده، این متن رو دریافت میکنه (فقط یه بار در هر ۳۰ دقیقه).

## 🔐 امنیت

1. هیچوقت `API_ID`, `API_HASH`, `.session` و `.env` رو **جایی عمومی** (مثل گیت‌هاب پابلیک) قرار نده
2. روی VPS، دسترسی فایل `.env` رو محدود کن:
   ```bash
   chmod 600 .env userbot_session.session
   ```
3. توصیه میشه سرویس رو زیر یک کاربر غیر root اجرا کنی
4. از 2FA روی اکانت تلگرامت استفاده کن

## 🐛 رفع اشکال

**سوال:** سرویس بالا نمیاد یا خطا میده
```bash
journalctl -u userbot -n 50 --no-pager
tail -50 /opt/telegram_userbot/userbot.err.log
```

**سوال:** آیا بن میشم؟
- تلگرام نسبت به یوزربات‌های **اسپم** حساسه
- این ربات فقط به پیام‌ها جواب میده و اسپم نمی‌کنه، پس ریسک پایینه
- ولی اگه تعداد پیام/دقیقه زیاد بشه یا مشکوک باشه ممکنه محدودیت اعمال بشه

**سوال:** میخوام AFK به صورت پیش‌فرض روشن باشه
- توی `userbot.py` خط `afk_enabled = False` رو به `True` تغییر بده
