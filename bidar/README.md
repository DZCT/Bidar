## 📖 درباره

**Bidar** یه یوزربات سبک و امن برای تلگرامه که:

- اکانتت رو **۲۴/۷ آنلاین** نگه میداره
- وقتی سرت شلوغه، **پاسخ خودکار هوشمند** میده
- با یه سری **دستور سفارشی** زندگی تلگرامیت رو راحت‌تر میکنه
- همه دستورات **فقط در دست خودت** — کسی نمیتونه از بیرون کنترلش کنه

| 🛡 **فقط چت خصوصی** | گروه‌ها، کانال‌ها و ربات‌ها نادیده گرفته میشن |

## 🚀 نصب تک‌خطی (روی VPS)

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/YOUR_USERNAME/bidar/main/install.sh)
```

> 🔁 آدرس بالا رو بعد از آپلود به گیت‌هاب، با یوزرنیم خودت جایگزین کن.

اسکریپت نصب به صورت خودکار:

1. ✅ **پیش‌نیازها رو چک میکنه** (Python 3.10+, pip, venv, git, curl)
2. ✅ **هر چی نصب نباشه رو نصب میکنه** (تشخیص خودکار apt/dnf/yum/pacman/apk)
3. ✅ **سورس رو کلون میکنه** توی `/opt/bidar`
4. ✅ **محیط مجازی پایتون** میسازه و وابستگی‌ها رو نصب میکنه
5. ✅ **تعاملی ازت می‌پرسه**: API_ID، API_HASH، شماره موبایل، متن AFK
6. ✅ **لاگین اولیه** رو انجام میده (کد SMS رو وارد میکنی)
7. ✅ **سرویس systemd** میسازه تا Bidar دائمی بالا باشه

## 📥 نصب دستی (جایگزین)

```bash
git clone https://github.com/YOUR_USERNAME/bidar.git /opt/bidar
cd /opt/bidar
bash install.sh
```

یا کاملاً دستی:

```bash
git clone https://github.com/YOUR_USERNAME/bidar.git
cd bidar
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
nano .env          # API_ID، API_HASH و PHONE رو پر کن
python bidar.py    # اولین اجرا → وارد کردن کد SMS
```

## 💬 دستورات (فقط خودت می‌تونی تایپ کنی)

| دستور | کاربرد |
|---|---|
| `.help` / `.menu` / `.commands` | نمایش راهنمای کامل دستورات |
| `.alive` | چک کردن اینکه ربات زنده و آنلاینه |
| `.ping` | تست تاخیر پاسخ ربات (ms) |
| `.stats` | آمار کامل (آپ‌تایم، پیام‌ها، پاسخ‌های خودکار) |
| `.afk [متن]` | روشن/خاموش کردن حالت غایب با متن دلخواه |
| `.id` | نمایش آیدی چت فعلی (و کاربر اگه ریپلای بزنی) |
| `.restart` | ری‌استارت سرویس (فقط در systemd) |

### مثال
```
.afk بعد از ظهر برمیگردم 🌙
```
هر کی بهت پیام خصوصی بده، این متن رو دریافت میکنه — هر ۳۰ دقیقه فقط یک بار.

## 🔒 امنیت

Bidar با چند لایه امنیتی طراحی شده:

1. **دو لایه چک مالک:**
   - لایه اول: `outgoing=True` → فقط پیام‌هایی که از اکانت خودت ارسال میشن trigger میشن
   - لایه دوم: `sender_id == OWNER_ID` → حتی اگه لایه اول دور زده بشه، این لایه جلوی اجرا رو میگیره
2. **بدون ذخیره پسورد** — فقط فایل `.session` تلگرام
3. **فایل `.env` با permission 600** (فقط مالک میتونه بخونه)
4. **`.gitignore`** جلوی آپلود اشتباهی `.env` و `.session` رو میگیره

### توصیه‌های مهم 🛡
- حتماً **2FA** روی اکانت تلگرامت فعال کن
- `API_ID`, `API_HASH`, `.session` رو هیچ جای عمومی نذار
- از یوزر غیر root برای سرویس استفاده کن (اگه ممکنه)

## 🧰 دستورات مفید سرور

```bash
systemctl status bidar           # وضعیت سرویس
systemctl restart bidar          # ری‌استارت
systemctl stop bidar             # توقف
journalctl -u bidar -f           # لاگ زنده
tail -f /opt/bidar/bidar.log     # لاگ فایل
```

## 🐛 رفع اشکال

<details>
<summary>سرویس بالا نمیاد</summary>

```bash
journalctl -u bidar -n 100 --no-pager
tail -100 /opt/bidar/bidar.err.log
```
</details>

<details>
<summary>آیا اکانتم بن میشه؟</summary>

Bidar **اسپم نمیکنه** — فقط به پیام‌ها پاسخ میده با cooldown.  
اگه از اکانت‌های خیلی جدید استفاده کنی یا cooldown رو خیلی پایین بذاری، ممکنه ریسک داشته باشه. برای امنیت بیشتر:
- از اکانت‌های قدیمی‌تر استفاده کن
- `AFK_COOLDOWN` رو پایین‌تر از ۶۰۰ (۱۰ دقیقه) نذار
</details>

<details>
<summary>میخوام AFK به صورت پیش‌فرض روشن باشه</summary>

توی `bidar.py`، خط `afk_enabled = False` رو به `True` تغییر بده.
</details>
