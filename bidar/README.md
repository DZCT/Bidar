## 📖 درباره

**Bidar** یه یوزربات سبک و امن برای تلگرامه که:

- اکانتت رو **۲۴/۷ واقعاً آنلاین** نشون میده (با رفرش خودکار هر ۴ دقیقه)
- **پاسخ خودکار هوشمند** قابل تنظیم در زمان اجرا
- همه تنظیمات رو **توی چت خود تلگرام** میتونی تغییر بدی و دوباره ذخیره میشن
- همه دستورات **فقط در دست خودت** — کسی نمیتونه از بیرون کنترلش کنه

## ✨ قابلیت‌ها

| قابلیت | توضیح |
|---|---|
| 🟢 **آنلاین واقعی** | ارسال `UpdateStatusRequest` هر ۴ دقیقه — بقیه «آنلاین» می‌بیننت |
| 💤 **پاسخ خودکار هوشمند** | قابل خاموش/روشن و ویرایش متن در زمان اجرا |
| 💾 **تنظیمات پایدار** | همه تغییرات در `bidar_config.json` ذخیره میشن |
| 🔒 **قفل مالکیت** | دستورات فقط برای خود مالک اکانت (دولایه امن) |
| ⏳ **Cooldown هوشمند** | به هر نفر فقط یک بار در بازه زمانی پاسخ میده |
| 📊 **آمار زنده** | آپ‌تایم، پیام‌ها و پاسخ‌ها |
| 🛡 **فقط چت خصوصی** | گروه‌ها، کانال‌ها و ربات‌ها نادیده گرفته میشن |
| 📝 **لاگ فایل** | همه رویدادها برای بررسی |

## ❓ سوال رایج: آیا دیگران منو «آنلاین» می‌بینن؟

**بله** — وقتی `.online on` باشه، Bidar هر ۴ دقیقه یه بار به سرور تلگرام اعلام میکنه که شما آنلاین هستی. **البته تنظیمات privacy تلگرامت** (Settings → Privacy & Security → Last Seen) همچنان اعمال میشه، یعنی فقط کسانی که اجازه دارن وضعیتت رو ببینن، آنلاین بودنت رو می‌بینن.

## 💬 دستورات (فقط خودت می‌تونی تایپ کنی)

### 🔹 وضعیت آنلاین
| دستور | کاربرد |
|---|---|
| `.online on` | روشن کردن آنلاین دائم |
| `.online off` | خاموش کردن (آفلاین نشون داده میشی) |
| `.online` | جابه‌جا (toggle) |
| `.interval <ثانیه>` | تنظیم بازه رفرش (پیش‌فرض ۲۴۰ = ۴ دقیقه) |
| `.interval 3m` | پشتیبانی از دقیقه (m) هم |
| `.interval` | نمایش مقدار فعلی و محدوده مجاز |

### 🔹 پاسخ خودکار
| دستور | کاربرد |
|---|---|
| `.reply on` | روشن کردن پاسخ خودکار |
| `.reply off` | خاموش کردن |
| `.reply` | جابه‌جا (toggle) |
| `.setmsg <متن>` | ویرایش متن پاسخ خودکار |
| `.afk <متن>` | میانبر: ست متن + روشن کردن |
| `.afk off` | خاموش کردن سریع |

### 🔹 اطلاعات و ابزار
| دستور | کاربرد |
|---|---|
| `.help` / `.menu` / `.commands` | راهنمای کامل |
| `.alive` | چک زنده بودن ربات |
| `.ping` | تست تاخیر (ms) |
| `.stats` | همه آمار و تنظیمات فعلی |
| `.id` | آیدی چت/کاربر |
| `.restart` | ری‌استارت (در حالت systemd) |

### مثال استفاده
```
.online on               →  حالا همیشه آنلاین نشون داده میشی
.setmsg بعد از ۶ برمیگردم 🌙
.reply on                →  پاسخ خودکار فعال شد
.stats                   →  بررسی تنظیمات
```

## 🔒 امنیت

Bidar با چند لایه امنیتی طراحی شده:

1. **دو لایه چک مالک:**
   - `outgoing=True` → فقط پیام‌های ارسالی از اکانت خودت
   - `sender_id == OWNER_ID` → حتی اگه لایه اول دور زده بشه
2. **بدون ذخیره پسورد** — فقط فایل `.session` تلگرام
3. **`.env` با permission 600** (فقط مالک میتونه بخونه)
4. **`.gitignore`** جلوی آپلود اشتباهی `.env` و `.session` رو میگیره

### توصیه‌های مهم 🛡
- حتماً **2FA** روی اکانت تلگرامت فعال کن
- `API_ID`, `API_HASH`, `.session` رو هیچ جای عمومی نذار
- از یوزر غیر root برای سرویس استفاده کن (اگه ممکنه)

journalctl -u bidar -n 100 --no-pager

<details>
<summary>آیا اکانتم بن میشه؟</summary>

Bidar **اسپم نمیکنه** — فقط به پیام‌ها پاسخ میده با cooldown.  
برای امنیت بیشتر:
- از اکانت‌های قدیمی‌تر استفاده کن
- `autoreply_cooldown` رو پایین‌تر از ۶۰۰ (۱۰ دقیقه) نذار
- `AFK_COOLDOWN` در `.env` قابل تنظیمه
</details>

<details>
<summary>دیگران منو آنلاین نمی‌بینن</summary>

1. بررسی کن `.online on` باشه → `.stats` بزن ببین
2. تنظیمات privacy تلگرامت رو چک کن: Settings → Privacy and Security → Last Seen & Online
3. چند دقیقه صبر کن تا رفرش اولیه انجام بشه
</details>
